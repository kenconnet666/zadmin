## 2. 根因与修复

### 2.1 Docs 全局 reset 覆盖组件 typography

- 原因：Docs 的未分层 `button,input,select { font: inherit; }` 优先于 `@layer zui.components`，把 Button recipe 的字号、行高和字重一起重置。
- 修复：只继承 `font-family`；整个 Docs reset 放入 `@layer docs-reset`，并通过 `@layer docs-reset, zui` 固定低于组件层的级联顺序。
- 门禁：`audit-system.mjs` 禁止 Docs reset 使用 `font` shorthand，并要求 reset layer/prelude 存在。
- 结果：Button small/medium/large 恢复为 24/32/48px control box 与 12/14/18px 字号；组件页 section/card 间距恢复为外边距语义。

### 2.2 Recipe variant 被跨组件 canonical 去重破坏

- 原因：ICSS Registry 会跨 recipe 复用相同 canonical rule。一个 variant 原子类若先被其他组件注册，而当前 recipe 的 base 类后注册，两者同 specificity 时，base 会反向覆盖 variant；`ZFileUpload invalid` 已用真实浏览器复现为 `data-invalid=true` 但边框仍是普通色。
- 修复：Recipe 将 authored precedence 编码进 selector specificity：`base` → variant 声明顺序 → compound 声明顺序；Slot Recipe 使用同一规则。Utilities 仍通过更后的 `zui.utilities` layer 覆盖组件样式。
- 回归：Registry/Recipe 单测证明同 canonical、不同优先级生成不同 class；浏览器证明 FileUpload invalid 边框恢复危险色；14 个重点 browser spec、69 个测试集中通过。

### 2.3 弹层与窄视口几何

- Select、Combobox、MultiSelect、TreeSelect、Cascader、ColorPicker 统一使用 shared floating content sizing，支持 `matchWidth`，设置 viewport-aware max width/max height 和滚动边界。
- CJK option 强制单行；Docs 主题选择器使用 intrinsic content width，不再继承窄 Trigger 宽度。
- `ZInput` 补 `box-sizing:border-box`，避免显式 80px 输入实际变成 114px。
- Popover content 增加有界 overflow。
- `ZDialogContent` 补 `box-sizing:border-box`，修复 414px 视口下 90% width 再叠加 padding/border 导致右侧约 4px 溢出；Dialog、AlertDialog、CommandPalette 同时受益。
- Docs 主题弹层在 769px 桌面断点自动化验证：宽度大于 120px、六个选项均 `nowrap`、content 不越过 viewport、纵向 overflow 为 `auto`。

### 2.4 `size` API 真实生效

- Docs 示例的横向 Stack 改为 `align="center"`，避免父级 stretch 把不同尺寸 Button 全部拉成 48px。
- `ZDatePicker`、`ZDateRangePicker` 把 `resolvedSize` 继续传给外层 `ZInputGroup`；此前只有内部字段和按钮变化，外框仍固定 medium。
- 浏览器验证 DatePicker small 外框 26px、DateRangePicker large 外框 50px（均包含上下 1px border）。
- 建立基础 control、form owner、display、input、navigation、overlay 和 compound member 的尺寸/几何矩阵。

### 2.5 API 生成与所有权

- 生成器支持 `RecipeVariants` / `SlotRecipeSelection`，Button 等 recipe-backed prop 不再从 API facts 消失。
- Workspace type graph 支持 Svelte/TS 本地声明继承，并修复 `interface extends Omit<...>` 的 `ExpressionWithTypeArguments` 遍历；公开 facts 从 1706 补全为 1756。
- 非同目录复合成员增加显式 `memberApis`，`ZForm` 页面现在完整展示 `ZFormField` 的 `controlId/label/size/ref/...`。
- API runtime audit 验证：静态声明 → `$props` 解构 → 实际 `{...rest}` DOM 转发 → metadata/default 一致性。
- 新增受控状态三元组门禁，覆盖 `value/defaultValue/onValueChange`、`open`、`checked`、`pressed`、active/focused value、files、step、sort、column visibility/width 等家族。
- `ZTagsInput` 主 API 统一为 `value/defaultValue/onValueChange`，草稿统一为 `inputValue/defaultInputValue/onInputValueChange`；仅真实历史别名 `values/defaultValues` 保留 deprecated 兼容和冲突保护。
- `ZComboboxInput` 移除由父 `ZCombobox` 所有、传入后会被覆盖的 `value/defaultValue/onValueChange/onFormReset` 叶子 API。
- Carousel 原生 `aria-label` 与 deprecated `ariaLabel` 的关系改为条件必填，不再把可选类型错误展示为无条件 required。
